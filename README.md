
# DevQuiz - Aplicación Web de Cuestionarios

DevQuiz es una aplicación web desarrollada para crear cuestionarios personalizados, agregar preguntas, practicar conocimientos y consultar los resultados obtenidos. Su objetivo es facilitar el aprendizaje y la autoevaluación mediante una interfaz intuitiva y fácil de utilizar.

Este proyecto fue desarrollado como parte de mi aprendizaje en Ingeniería de Software, aplicando tecnologías fundamentales del desarrollo web.

## Características

- Creación de cuestionarios personalizados.
- Agregar y administrar preguntas.
- Realización de cuestionarios para practicar conocimientos.
- Consulta de resultados obtenidos.
- Historial de intentos realizados.
- Panel principal con estadísticas de cuestionarios, preguntas e intentos.
- Modo claro y modo oscuro.

## Tecnologías utilizadas

- HTML5: estructura de la aplicación.
- CSS3: diseño, estilos y adaptación de la interfaz.
- JavaScript: funcionalidades e interacción de la aplicación.

## Instalación y ejecución

Para ejecutar DevQuiz en tu computadora, sigue estos pasos:

1. Clona este repositorio o descarga el proyecto como archivo ZIP.
2. Descomprime el proyecto si lo descargaste en formato ZIP.
3. Abre la carpeta del proyecto en Visual Studio Code.
4. Abre el archivo `index.html` en tu navegador.

También puedes utilizar la extensión Live Server de Visual Studio Code para ejecutar la aplicación desde un servidor de desarrollo local.

## Almacenamiento de datos

La aplicación cuenta con un módulo de almacenamiento llamado `storage.js`, encargado de gestionar los datos de la aplicación.

Si se utiliza almacenamiento local del navegador, los cuestionarios, preguntas e intentos se guardan en el dispositivo y no se sincronizan automáticamente entre diferentes dispositivos.

Los datos podrían perderse al borrar el almacenamiento del navegador.
